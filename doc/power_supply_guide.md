# ESP32-C5 供电指南（超详细版）


---

## 先回答你最关心的问题

### Q: ESP32 的电源从哪来？

**最简单的答案：用 USB 线插电脑就行！**

```
电脑 USB 口 ──────→ USB-C 数据线 ──────→ ESP32-C5 的 USB-C 口
                                              │
                                              └──→ ESP32 有电了！
                                                   可以正常工作
                                                   还能看调试日志
```

### Q: 可以同时连电脑和飞控吗？

**可以！完全不冲突！**

```
┌─────────────┐                        ┌─────────────┐
│   电脑      │                        │    飞控     │
│  (QGC等)    │                        │  (Pixhawk)  │
└──────┬──────┘                        └──────┬──────┘
       │                                      │
       │ USB-C 数据线                         │ 2根杜邦线
       │ (供电 + 调试)                        │ (只传数据)
       │                                      │
       ▼                                      ▼
┌──────────────────────────────────────────────────────┐
│                  ESP32-C5-DevKitC                     │
│                                                      │
│   USB-C 口 ←── 供电 + UART0 调试                     │
│                                                      │
│   GPIO4    ←── UART1 接收飞控数据                     │
│                                                      │
│   GND      ←── 共地（必须连！）                       │
└──────────────────────────────────────────────────────┘
```

**两条路完全独立，互不影响：**

| 接口 | 用途 | 说明 |
|------|------|------|
| USB-C 口 | 供电 + 调试日志 | 连电脑，看串口输出 |
| GPIO4 + GND | 接收飞控数据 | 连飞控 TELEM1 |

## 三种供电方式详解

### 方式一：USB 供电（推荐新手使用）✅

**适用场景：** 桌面调试、坐在电脑前测试

**你需要：**
- ESP32-C5-DevKitC
- 一根 USB-C 数据线（不能是纯充电线！）
- 一台电脑

**怎么做：**
1. 把 USB-C 线一头插电脑 USB 口
2. 另一头插 ESP32-C5 的 USB-C 口
3. 搞定！ESP32 有电了

**优点：**
- 最简单，不用操心
- 顺便还能看调试日志（`idf.py monitor`）
- 电脑能给 ESP32 提供足够电流（500mA~1A）

**缺点：**
- 必须连着电脑，不能随便移动

---

### 方式二：移动电源供电

**适用场景：** 没有电脑在身边，但需要测试

**你需要：**
- 一个手机充电宝（USB 输出口）
- 一根 USB-A 转 USB-C 线

**怎么做：**
1. 充电宝插 USB-A 转 USB-C 线
2. 插到 ESP32-C5 的 USB-C 口
3. 搞定！

**优点：**
- 可以带着 ESP32 到处走
- 充电宝容量大，能用很久

**缺点：**
- 看不到调试日志（除非用蓝牙或 WiFi）

---

### 方式三：飞控给 ESP32 供电（高级）

**适用场景：** 实际装机，不想用独立电源

**你需要：**
- 飞控 TELEM1 端口的 +5V 输出
- 1 根额外的杜邦线

**怎么做：**
1. 飞控 TELEM1 的 Pin 1（+5V）用杜邦线连到 ESP32 的 5V 引脚
2. ESP32 从飞控取电

**注意：**
- 不是所有飞控的 TELEM1 都有 +5V 输出！
- 有些飞控 Pin 1 是 GND，不是 +5V
- **务必先查阅你的飞控手册！**

**优点：**
- 一体化，不需要额外电源
- 飞控上电 → ESP32 自动上电

**缺点：**
- 可能增加飞控的电源负担
- 接错了可能烧东西

---

## 你现在应该怎么做？

### 场景 A：坐在电脑前调试

**推荐方案：USB 供电 + 飞控数据**

```
1. ESP32 用 USB-C 线连电脑 ←── 供电 + 调试
2. ESP32 GPIO4 连飞控 TX    ←── 数据
3. ESP32 GND 连飞控 GND     ←── 共地
```

**效果：**
- 电脑能看串口日志（`idf.py monitor`）
- ESP32 能收飞控数据
- 两边都有电，都正常工作

### 场景 B：户外测试，没带电脑

**推荐方案：充电宝供电 + 飞控数据**

```
1. ESP32 用充电宝供电       ←── 供电
2. ESP32 GPIO4 连飞控 TX    ←── 数据
3. ESP32 GND 连飞控 GND     ←── 共地
```

**效果：**
- ESP32 能收飞控数据
- 看不到日志（但可以用 BLE 广播验证）

## 常见问题（超级简单版）

### Q1: USB-C 线插上去没反应？

**可能原因：** 用的是纯充电线，不是数据线

**判断方法：**
- 充电线：只能充电，电脑识别不到设备
- 数据线：能充电 + 传输数据，电脑能识别

**解决：** 换一根能传数据的 USB-C 线（手机原装线通常可以）

---

### Q2: 同时插电脑和连飞控，会不会把电脑烧了？

**不会！**

原因：
- USB-C 口 → ESP32 的 UART0（通过 USB 转 UART 芯片）
- GPIO4 → ESP32 的 UART1

这两个是**完全独立的电路**，互不影响。

就像你家：
- 客厅的灯和卧室的灯，用的是不同的开关
- 你同时开两个灯，不会短路

---

### Q3: 飞控能给 ESP32 供电吗？

**能，但不推荐新手尝试。**

原因：
- 飞控 TELEM1 的 +5V 输出电流有限（通常只有 100~500mA）
- ESP32 在 BLE 广播时可能瞬间需要较大电流
- 如果电流不够，ESP32 可能会重启

**新手还是用 USB 供电最安全。**

---

### Q4: ESP32 和飞控的 GND 必须连吗？

**必须连！**

原因：
- 信号需要参考电平（0V）
- 如果不共地，ESP32 不知道飞控发的信号是 0 还是 1
- 就像两个人打电话，不接地线就听不清

**不连 GND 的后果：**
- 数据全是乱码
- 或者完全收不到数据

---

### Q5: 我可以先用 USB 供电调试，然后再换成充电宝吗？

**可以！随时切换，没问题。**

ESP32 断电后再上电，程序会从头开始运行。
你不需要改代码或重新烧录。

## 接线检查清单（每次接线前看一遍）

### 第一次接线（桌面调试）

- [ ] ESP32 用 USB-C 线连电脑
- [ ] 电脑能识别到 COM 口
- [ ] `idf.py monitor` 能看到日志

### 连接飞控数据

- [ ] 飞控已断电
- [ ] 找到飞控 TELEM1 的 TX 引脚
- [ ] 找到飞控 TELEM1 的 GND 引脚
- [ ] 杜邦线：飞控 TX → ESP32 GPIO4
- [ ] 杜邦线：飞控 GND → ESP32 GND
- [ ] 没有接错，没有短路

### 通电测试

- [ ] 先给飞控上电
- [ ] 再给 ESP32 上电（插电脑 USB）
- [ ] 串口日志显示正常
- [ ] `frames` 数值在增长
