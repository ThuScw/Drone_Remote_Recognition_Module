  项目理解摘要

  项目：ESP32-S3 无人机远程识别（RID）广播模块，符合 GB 46750-2025 标准，当前分支
  feature/esp32s3，最近提交 S3-v3.2.1。

  数据流：
  飞控 USB (VID 0x1B8C/PID 0x0036)
    → USB Host CDC-ACM (flight_data.cpp, 只读模式+DTR/RTS清除)
    → mavlink_parser (v1/v2双协议, 7种消息, CRC-16/MCRF4XX)
    → FlightData
    → RIDBroadcastManager::update()  (~10ms循环)
        ├─ validateAndBuildPacket  (1s刷新, 范围验证→表3哨兵值)
        ├─ handleStatusTransition  (消抖 300ms/500ms, 紧急绕过)
        ├─ handleBroadcast         (800ms, 永不跳过, BLE5 EXT_ADV)
        ├─ handleFlightLog         (10s, wear_levelling环形缓冲)
        └─ handleSelfTest          (5s自检 + 3级BLE自修复)

  核心合规设计：
  - M 字段始终存在，缺失编码为表3未知哨兵值（位置 0xFFFFFFFF、航迹/速度 0xFFFF）
  - 永不跳过广播（满足"全过程自动持续发送"）
  - 操作员位置三级回退：HOME_POSITION → 起飞点 → 哨兵值
  - 空中不拉闸、地面拉闸（GB 46750 5.1.7）
  - CRC 风暴恢复（200帧失败 → USB重连 + 5s冷却）
  - Unix 时间戳从 SYSTEM_TIME 授时
